# 분석 실패 기록의 민감 정보 차단

2026-09-15

`AnalysisJobProcessor`의 Worker 호출 실패 재시도 경로는 이전에 예외의 `getMessage()`를 `analysis_jobs.last_error`에 저장했다. 라이브러리나 Worker 예외에는 토큰, 접속 URL, 요청 내용이 포함될 수 있어 원문을 저장하지 않는다. 대신 기존 최종 실패 코드와 같은 `PROMETHEUS_UNAVAILABLE`만 저장한다.

재시도 횟수와 정책의 추가 관측 지연은 유지한다. 최대 시도 횟수에 도달하면 기존처럼 `INCONCLUSIVE`, 빈 근거 `[]`, 고정 사유 코드로 완료하고 `PAUSE_ROLLOUT` 명령을 예약한다. 예외 메시지를 감사나 명령 payload에 추가하지 않는다.

회귀 테스트는 합성 토큰·비밀번호·URL이 들어간 예외의 안전한 재시도 기록, 메시지가 없는 예외의 동일한 기록, 최대 시도 후 일시정지 명령을 검증한다. 테스트는 mocked Worker와 저장소, 실제 AnalysisJob 상태 전이를 사용하며 외부 호출을 하지 않는다.

로컬 서버 전체 `mvnw --batch-mode verify`에서 90개 테스트가 실패·오류·건너뜀 없이 통과했다.

이번 변경은 예외 기반 재시도 경로에 한정된다. Worker가 정상 응답으로 반환하는 사유·근거의 검증이나 모든 로그의 전역 마스킹을 구현한 것은 아니다. 기존 DB 기록을 조회·삭제하지 않았으며 공개 배포 이미지도 변경하지 않았다.
