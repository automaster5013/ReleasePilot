# 분석 자격 증명 누락 시 fail-closed

2026-09-15

분석 요청 생성 시 Prometheus 연결의 비밀 참조를 읽지 못하면 이전에는 null 토큰으로 Worker를 호출할 수 있었다. 비밀 참조가 없는 연결의 익명 접근은 의도된 동작이지만, 비밀 참조가 있는 연결을 익명 접근으로 낮추지 않는다.

비밀 참조가 설정된 경우 값 누락, null/공백 토큰, resolver의 RuntimeException을 `SECRET_UNAVAILABLE`로 처리한다. Worker를 호출하지 않고 `INCONCLUSIVE` 결과와 빈 근거를 기존 재시도/완료 경로에 전달한다. 정책의 추가 관측 지연과 최대 시도 횟수는 유지하며, 최대 횟수에 도달하면 `PAUSE_ROLLOUT`을 예약한다. 조회 예외의 원문은 저장하지 않는다.

비밀 참조가 없는 연결은 resolver를 호출하지 않고 익명 요청을 유지한다. 정상 비밀 값은 기존처럼 Worker 요청에 전달한다. 재시도마다 값을 다시 조회하므로 자격 증명 복구 후 다음 시도에서 분석을 재개할 수 있다.

회귀 테스트 6개는 값 누락, 공백, resolver 예외, 최종 일시정지, 익명 요청 유지, 정상 토큰 전달을 검증한다. mocked Worker/저장소와 실제 AnalysisJob 상태 전이를 사용하며 외부 서비스나 운영 비밀을 조회하지 않는다.

로컬 서버 전체 `mvnw --batch-mode verify`에서 96개 테스트가 실패·오류·건너뜀 없이 통과했다.

후속 검증은 null/빈 문자열/공백/탭·개행 토큰을 각각 검사하고, 다음 예약 시도 시각에 자격 증명을 다시 읽어 Worker의 PASS 결과와 PROMOTE 예약으로 복구되는 경로를 추가했다. 저장소의 예약 시각 조회는 mock이며 DB locking/스케줄러 통합 검증을 대신하지 않는다. 로컬 서버 전체 테스트는 100개가 통과했다.

코드 수준 보강이며 공개 배포 이미지는 변경하지 않았다. 다른 분석 요청 구성 오류의 복구, Secrets Manager/Vault 활성화, 실제 운영 자격 증명 교체는 이 작업에 포함하지 않는다.
