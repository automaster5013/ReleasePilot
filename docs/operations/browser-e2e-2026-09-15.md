# 공개 데모 브라우저 검증 (2026-09-15)

## 결과: 실패, 후속 흐름 미검증

대상은 `https://releasepilot.kr/`, 브라우저는 Codex 내장 브라우저다. 운영 릴리스 mutation은 실행하지 않았다.

- 초기 화면: 제목, 릴리스 snapshot, 판정 근거와 감사/세션 영역이 렌더링됐다.
- 로그인 전 안전성: Promote, Pause, Resume, Abort 및 릴리스 불러오기/새로고침 버튼이 비활성으로 표시됐다. Promote의 enabled 값도 false였다.
- 데모 진입: `읽기 전용 데모` 클릭 후에도 DEMO SNAPSHOT과 빈 최근 릴리스 목록이 유지됐다. 새로고침 후 클릭에서도 같은 증상을 확인했다.
- 콘솔: 두 문서 로드에서 `Minified React error #412`가 기록됐다. 오류 위치는 `/_next/static/chunks/0cegfsgm6lvdz.js`다. 이 오류와 로그인 미반응의 인과관계 및 서버/브라우저 측 원인은 아직 확정하지 않았다.
- VIEWER 로그인, 실제 릴리스 조회/선택, 감사 이력, 세션 유지와 로그인 후 권한은 진입 실패 때문에 미검증이다. 로그인 전 비활성 버튼만으로 VIEWER 권한 검증 성공을 판단하지 않는다.

직전 점검의 DNS 오류는 이번 연결에서 재현되지 않았다. 이전 HTTP 헬스 점검 성공은 브라우저 상호작용 성공을 의미하지 않는다.
