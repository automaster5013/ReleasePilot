# 로그아웃 UI 검증

2026-09-16: 로그인 상태에 로그아웃 버튼을 추가했다. 서버 `/control-api/session/logout`에 CSRF 헤더를 포함한 POST를 보낸다. 요청 중 재진입을 막고 버튼을 비활성화한다. 성공 시 전체 페이지를 새로 열어 로그인 상태와 보관된 릴리스 화면 상태를 폐기한다. 오류 시 기존 세션 표시를 유지하고 오류 안내와 버튼 복구로 수동 재시도를 허용한다.

현재 production build, lint, 단위 테스트 35개 및 전체 fixture E2E 89개가 통과했다. 이후 서버 403 거부·수동 재시도 회귀 테스트를 추가하고 로그아웃 관련 2개 테스트를 실행해 모두 통과했다. 테스트 총수는 90개이며 신규 추가 후 전체 90개 실행은 아직 하지 않았다.

후속 전체 검증에서 새 production build·lint·단위 35개·전체 fixture E2E 90개가 모두 통과했다. 실제 운영 배포와 Cognito 자체 로그아웃 검증은 포함하지 않았다.

정상 흐름에서는 로그아웃 후 DEMO SNAPSHOT, 로그아웃 버튼 제거·새로고침 비활성화와 재로드 이후 미인증 상태를 확인한다. 거부 흐름에서는 오류 안내·기존 VIEW ONLY 표시·버튼 활성화, 최초 요청 1회와 수동 재시도 성공 후 총 2회를 확인한다.

검증은 로컬 production standalone 서버와 격리 API fixture에서 실행했다. 실제 Cognito 세션 종료나 운영 브라우저 로그아웃을 증명하지 않는다. UI 로그아웃은 ReleasePilot 서버 세션 종료이며 Cognito 로그인 쿠키는 별도로 남을 수 있다. 실제 서버 처리 후 응답 유실과 실패의 모든 유형은 이번 테스트에 포함하지 않았다.
