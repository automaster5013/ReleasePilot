# ADR-003: 릴리스 정책은 버전이 지정된 제한형 JSON으로 표현한다

- 상태: 승인됨
- 결정일: 2026-09-14
- 대상: ReleasePilot MVP

## 배경

ReleasePilot의 판단은 사람이 이해하고 재현할 수 있어야 한다. 범용 스크립트나 표현식 언어는 유연하지만 보안, 결정성, 검증과 UI 편집을 어렵게 만든다. 관계형 컬럼만으로 모든 정책을 표현하면 버전 스냅샷과 향후 규칙 확장이 번거롭다.

## 결정

- 정책 정의는 JSON 문서로 저장한다.
- JSON Schema와 Control Plane의 의미 검증을 모두 통과해야 활성화할 수 있다.
- MVP에서 허용하는 지표와 연산자는 명시적인 allowlist로 제한한다.
- 정책 버전은 활성화 후 불변이다.
- 릴리스 승인 시 전체 정책 문서와 checksum을 PolicySnapshot으로 저장한다.
- 사용자 코드, 템플릿 코드, 임의 PromQL 및 범용 표현식 실행을 허용하지 않는다.

## 결과

- 정책을 API, 데이터베이스와 감사 이벤트에서 동일한 형태로 다룰 수 있다.
- 과거 릴리스의 판정을 적용 당시 정책으로 재현할 수 있다.
- 새 규칙 추가 시 schemaVersion 호환성을 관리해야 한다.
- 고급 사용자가 임의 조건을 표현하는 기능은 MVP 범위에서 제외된다.

## 재검토 조건

- 내장 규칙만으로 실제 사용 사례를 표현하기 어려운 경우
- 정책 문서 마이그레이션 비용이 지나치게 커지는 경우
- 외부 정책 엔진 연동이 제품 요구사항이 되는 경우
